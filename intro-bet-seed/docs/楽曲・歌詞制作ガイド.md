# 🎼 楽曲・歌詞制作ガイド

> Suno でイントロベット用の楽曲を作るときの手引きです。
> **歌詞のワード配分がそのままゲームバランスになります。** 感覚で書かず、この手順に沿ってください。

---

## 1. 全体の流れ

```
① 歌手キャラを選ぶ            → docs/歌手キャラクター設計ガイド.md
② ワード配分を設計する         → §2
③ 歌詞を書く                  → §3
④ Suno で生成する（2テイク）   → §4
⑤ イントロ長を計測する         → §5
⑥ メタデータを登録する         → §6
```

---

## 2. ワード配分の設計（最重要）

歌詞を書く前に、**その曲にどのティアのワードを何個入れるか**を決めます。

### 2.1 標準配分

| ティア | 1曲あたりの目安 |
|---|---|
| 堅い (Common) | 4〜5個 |
| 中間 (Uncommon) | 3〜4個 |
| 穴 (Rare) | 1〜2個 |
| 大穴 (Jackpot) | 0〜1個 |
| **合計** | **8〜12個** |

### 2.2 なぜこの配分なのか

出題時は、**曲を一切見ずに**辞書から6個の候補ワードが抽出されます（仕様書§4.3）。
そのうち**たまたまその曲の歌詞に入っていたもの**が正解になります。

つまり、

- 歌詞にレアワードが多く入っている曲 → 提示されたレア候補が当たりやすい＝**穴が来る回**
- 歌詞が堅いワードばかりの曲 → 堅いのしか当たらない＝**堅実な回**

**歌詞のワード配分が、そのままその回の"荒れ具合"を決めます。**

#### ⚠️ 1曲に辞書ワードを最低8個は入れること

システムは「正解が2個以上になるまで候補を引き直す」仕組みで動いています。
歌詞に含まれる辞書ワードが少なすぎる曲は、**何度引き直しても正解が2個に届かず**、
フォールバック処理（歌詞のワードを強制的にねじ込む）に落ちてしまいます。
そうなると倍率の前提が崩れ、その回だけ不公平になります。

**1曲あたり、辞書ワードを合計8個以上含めてください。**（標準配分に従えば自然に満たせます）

### 2.3 曲ごとに配分を変える

全曲を標準配分にすると、どの回も同じ手触りになって飽きます。
意図的に以下のような曲を混ぜてください。

| 曲のタイプ | 配分 | ゲーム上の効果 |
|---|---|---|
| **平易な曲** | 堅い6〜8個、中間2個、レアなし | 堅実に賭ければ当たる。初心者が息をつける回 |
| **標準の曲** | §2.1のとおり | 大半をこれにする |
| **レア盛りの曲** | 堅い3個、中間2個、穴3個、大穴1個 | 荒れる。歌手を知っている人が大勝ちする回 |

> **目安の比率: 平易2割 / 標準6割 / レア盛り2割**

### 2.4 キャラのモチーフ語を必ず織り込む

そのキャラのモチーフ語を、**曲の 50〜70% に登場させる**のが目標です（キャラ設計ガイド§1）。

- 全曲に入れる → 覚えたら作業ゲーになる
- ほとんど入れない → 覚える意味がない

**「たいてい入っているが、たまに裏切る」**を意図的に作ってください。
この"裏切り"がベテランを唸らせます。

## 3. 歌詞を書くときのルール

### 3.1 必ず守ること

| ルール | 理由 |
|---|---|
| **ワード辞書に載っている表記を使う** | 判定は辞書ベース。辞書外の語はゲームに登場しない |
| **1曲に同じワードを何度も使ってもよい** | 判定は「含むか否か」なので回数は無関係 |
| **サビより前にワードを詰め込まない** | ベット締切後に歌詞が流れる。締切前に答えが聞こえてはいけない |
| **イントロ中に歌声を入れない** | イントロ＝ベットタイム。歌が始まったら締切 |

### 3.2 ⚠️ 最重要：イントロに歌詞を含めない

このゲームは **「歌詞が始まる前に賭ける」** のがルールです。
イントロにハミングやコーラス（「Wow wow」等）が入るのは構いませんが、
**辞書ワードが聞こえてしまうと、そのラウンドが成立しません。**

Suno は指示しないとイントロにボーカルを入れることがあるので、
生成後に**必ずイントロを聴いて確認**してください。

### 3.3 新しいワードを使いたくなったら

歌詞を書いていて辞書にないワードを使いたくなったら、**辞書に追加してから**使ってください。
追加時は以下を決めます。

```yaml
id: kagerou
surface: 陽炎
aliases: [かげろう, カゲロウ]
# appearanceRate と tier と odds は、全曲データから自動計算されます
```

出現率・ティア・倍率は**手で決めません**。全楽曲を集計して自動算出します（仕様書§4.5）。
新しい曲を追加するたびに再計算が走るので、**倍率は曲が増えるにつれて変動します**。

## 4. Suno での生成

### 4.1 プロンプトに必ず入れること

```
- イントロを最低15秒確保すること（instrumental intro, at least 15 seconds）
- イントロにボーカルを入れないこと（no vocals in the intro）
- 歌手キャラの era / ジャンルに合った曲調
```

### 4.2 2テイクを活かす

Suno は1回の生成で **2テイク** を出力します。イントロベットではこれが資産になります。

| 使い方 | 内容 |
|---|---|
| **A. 良い方を採用** | 通常はこれ。もう片方は破棄 |
| **B. 両方を登録（バージョン違い）** | 同一歌詞・別アレンジとして両方使う |

**Bを選ぶ場合**、`versionGroupId` に共通のIDを振ってください（仕様書§9.3）。
プレイヤーが「これ、前に聴いたやつの別バージョンだ！」と気づいて大勝ちできる、
やり込み報酬の仕掛けになります。

> ⚠️ ただし**バージョン違いペアは全体の10〜20%に抑えてください**。
> 多すぎると単なる記憶ゲームになります（仕様書§6.1）。

---

## 5. イントロ長の計測

登録時に **イントロの実測秒数** が必要です。

1. 音源を再生し、**最初のボーカルが入る瞬間**の秒数を測る
2. その値を `introDurationSec` に記録する
3. ベット時間 `bettingWindowSec` は既定15秒。イントロがそれより短い曲は、
   イントロをループさせるか、ベット時間を短く設定する

## 6. メタデータ登録

1曲ごとに以下を登録します。

```yaml
id: shiasami-yoru-no-bara
title: 夜の薔薇
artistId: shiasami-reiji
audioUrl: /songs/shiasami-yoru-no-bara.mp3
introDurationSec: 18
bettingWindowSec: 15
lyrics: |
  （全歌詞をここに）
wordIds:                    # ★この曲に含まれる辞書ワード
  - ai                      # 愛
  - yoru                    # 夜
  - jounetsu                # 情熱
  - bara                    # 薔薇
versionGroupId: null
versionLabel: null
```

### 6.1 wordIds の付与方法

歌詞から辞書ワードを拾う作業は、**ビルド時のスクリプトで自動化**します
（形態素解析 kuromoji.js を使用）。ただし日本語は表記ゆれが激しいため、
**自動抽出の結果は必ず人の目で確認**してください。

よくある取りこぼし:
- 「愛して」「愛してる」→「愛」として拾えているか
- 「キミ」「きみ」→「君」として拾えているか
- 送り仮名や活用形の違い

> クイズ集アプリと同じく、**判定ミスは一発でユーザーの信頼を失います。**
> 「当たってたのに外れ扱いされた」はこのゲームで最悪の体験です。

## 7. 制作チェックリスト

1曲仕上げるごとに確認してください。

- [ ] イントロが15秒以上ある
- [ ] **イントロに辞書ワードが聞こえない**
- [ ] ワード配分が設計どおり（§2）
- [ ] キャラのモチーフ語が意図した比率で入っている
- [ ] 歌詞のワードがすべて辞書に登録されている
- [ ] `introDurationSec` を実測して記録した
- [ ] `wordIds` の自動抽出結果を目視確認した
- [ ] バージョン違いを登録する場合、`versionGroupId` を振った
- [ ] 実在の楽曲・歌手を想起させすぎていないか確認した
