# 🎤 歌手キャラクター設計ガイド

> イントロベットの歌手キャラを作るときの手引きです。
> **このゲームの面白さの8割はキャラ設計で決まります。** 理由は下記のとおり。

---

## 1. なぜキャラ設計がそこまで重要なのか

イントロベットでプレイヤーが上達するとは、**「この歌手なら、こういうワードを歌う」を覚えること**です。

つまりキャラ設計とは、**攻略対象そのものを作る作業**です。
キャラの語彙に一貫性がなければ、プレイヤーは何も覚えられず、
ゲームはただの運ゲーに堕ちます。逆に一貫性が強すぎると、
覚えた人が勝ち続けて初心者が勝てなくなります。

> **目指すバランス: 「傾向はある。でも必ずそうとは限らない」**

具体的には、キャラの得意ワード（モチーフ語）が
**そのキャラの曲の 50〜70% に登場する**くらいが理想です。
100%だと作業ゲー、30%以下だと覚える意味がありません。

---

## 2. キャラシート・テンプレート

新しい歌手を作るときは、この項目をすべて埋めてください。

```yaml
id: shiasami-reiji
name: 四浅見レイジ            # 架空の名前。実在の人物と誤認されないこと
era: 昭和スター               # どの時代・ジャンルの"タイプ"か
avatar: /artists/shiasami.png

# ── プレイヤーに公開する情報 ──
catchphrase: "夜と情熱の男"
personality: |
  自信家で情熱的。愛を語ることに一切のためらいがない。
  夜の街、赤い薔薇、燃えるような恋。とにかく熱い。
  でもふとした瞬間に見せる寂しさが人気の秘密。

# ── 内部データ（バランス調整用・非公開） ──
motifWords:                   # このキャラが好んで使うワード
  - 愛      # common
  - 夜      # common
  - 情熱    # uncommon
  - 薔薇    # rare
  - 灼熱    # jackpot
avoidWords:                   # このキャラは絶対に使わないワード
  - 教室
  - スマホ
  - 制服
targetMotifRate: 0.6          # モチーフ語がその曲に登場する目標比率
songCount: 8                  # 制作予定曲数
```

## 3. 権利上の絶対ルール ⚠️

実在の歌手の**作風をオマージュすること自体は合法**です。
曲の「雰囲気」「ジャンル」「歌い回し」に著作権はありません。
ただし、以下の2点を踏み越えると法的リスクが生じます。

### ❌ やってはいけないこと

| NG | なぜダメか |
|---|---|
| 実名をわずかに変えただけの名前 | 本人と誤認され、パブリシティ権の侵害・不正競争防止法上の問題になり得る |
| AI音声で本人の声質を再現する | 近年もっとも訴訟リスクが高い領域。声は人格権に近い扱いをされつつある |
| 「〇〇（実名）風」を売り文句にする | 本人の名声にただ乗りしている、と評価される |
| 実在の歌手の写真・イラストを流用 | 肖像権・著作権の直接侵害 |

### ✅ 安全な範囲

| OK | 理由 |
|---|---|
| 「昭和のきらびやかなスター歌手」というタイプのパロディ | 特定個人ではなくカテゴリのパロディ |
| その時代・ジャンルらしい曲調で作曲する | 作風に著作権はない |
| 明確に別人と分かるオリジナルの名前・ビジュアル | 誤認の余地がない |

> **判断基準**: 「あ、あの人っぽい」で止める。
> 「これ本人じゃないの？」と思われたらアウトです。

## 4. アーキタイプ案（8〜12キャラのたたき台）

特定の誰かではなく、**時代 × ジャンルのカテゴリ**として設計した案です。
語彙が被らないよう、モチーフ語を意図的に分散させています。

| # | タイプ | 世界観 | モチーフ語の方向性 |
|---|---|---|---|
| 1 | **昭和のスター歌手** | 夜の街、大人の恋、情熱 | 愛／夜／薔薇／情熱／灼熱 |
| 2 | **平成の青春バンド** | 教室、放課後、青すぎる衝動 | 君／青春／制服／自転車／放課後 |
| 3 | **令和のネットシンガー** | 都会の孤独、匿名性、深夜 | 心／画面／深夜／孤独／電子 |
| 4 | **叙情派フォークの人** | 故郷、家族、季節の移ろい | 故郷／母／季節／風／稲穂 |
| 5 | **アイドルグループ** | 恋、キラキラ、応援 | 好き／笑顔／未来／キラキラ／レインボー |
| 6 | **演歌の大御所** | 港、酒、耐える女／男 | 涙／酒／港／情け／北風 |
| 7 | **ロックの反逆児** | 反抗、疾走、自由 | 叫び／自由／révolution／檻／閃光 |
| 8 | **アニソン系ハイテンション** | 冒険、必殺技、仲間 | 仲間／光／運命／覚醒／銀河 |
| 9 | **シティポップの人** | 夏、海沿い、80年代の空気 | 夏／海／ドライブ／午後／蜃気楼 |
| 10 | **ヒーリング／ヒーラー系** | 癒し、祈り、自然 | 祈り／光／花／静寂／極光 |
| 11 | **ラッパー** | ストリート、努力、成り上がり | 街／金／夢／根性／頂点 |
| 12 | **童謡・こども向け** | 動物、食べ物、楽しい | ぞうさん／おやつ／たいよう／ともだち |

### 4.1 モチーフ語を分散させる意味

このゲームの醍醐味は**「歌手を見て、穴を狙うか判断する」**ことです。

- レア語（薔薇・灼熱・蜃気楼・極光など）を**キャラごとに割り振っておく**
- すると「シティポップの人の曲だから"蜃気楼"を狙ってみよう」という判断が成立する
- 全キャラが同じレア語を使うと、この読みが成り立たなくなる

> **原則: レアワード・大穴ワードは、必ず1〜2キャラの専有にする。**

これが仕様書§4.4で書いた
「歌手のクセ＝今回穴を狙うべきかの判断材料」を実際に成立させる仕組みです。

## 5. キャラ制作の進め方

```
STEP 1  アーキタイプを選ぶ（上の表 or 新規）
STEP 2  キャラシートを埋める（§2）
STEP 3  モチーフ語をワード辞書と突き合わせる
        → 辞書にないワードは新規登録する
        → レア語が他キャラと被っていないか確認する
STEP 4  ビジュアルを作る（未定 → §6）
STEP 5  そのキャラの曲を5〜10曲作る
        → docs/楽曲・歌詞制作ガイド.md へ
```

## 6. ビジュアル制作について【未決 ⚠️】

歌手キャラのビジュアルは、ゲームの「脱・AI感」を左右する重要要素です。
選択肢を挙げておくので、朝に方針を決めてください。

| 方法 | メリット | デメリット |
|---|---|---|
| **画像生成AI** | 早い・安い・大量に作れる | AI感が出やすい。商用利用条件の確認が必要 |
| **イラストレーターに依頼** | 統一感と個性が出る。作品としての強度が高い | 費用と時間がかかる |
| **シルエット / アイコン的表現** | 安価で統一感が出しやすい。想像の余地が残る | キャラの魅力を伝えづらい |
| **なつみさんが描く** | 完全にオリジナル。世界観の一貫性が最強 | 12人分の工数 |

> Claudeの推奨: **MVPはシルエット的な簡易表現で進め、面白さが確認できてから本格的なビジュアルに投資する。**
> Phase 1（ソロプロトタイプ）の目的は「面白いかを確かめること」なので、
> ここでビジュアルに時間をかけると、もし作り直しになったときの損失が大きくなります。
