# 🎵 イントロベット

> イントロだけを聴いて、歌詞を当てにいくベッティングゲーム。

オリジナル楽曲のイントロを聴いて「この曲の歌詞にどのワードが出てくるか」を予想し、
ゲーム内コインを賭け合う、スマホ持ち寄り型のパーティーゲームです。

## 遊びかた

1. ホストが部屋を作り、参加者は手元のスマホから参加コード / QR で入室
2. 歌手キャラが表示され、イントロが流れ始める
3. **イントロが鳴っている十数秒**のあいだに、提示された6つのワードにコインを賭ける
4. 歌が流れて歌詞が明かされる。当たったワードに賭けた人がコインを獲得
5. 全ラウンド終了後、**コインが一番多い人の勝ち**

## このゲームの面白さ

いわゆるイントロドンは「曲名を当てる」ゲームで、知識量がそのまま勝敗になります。
イントロベットは**曲名ではなく歌詞の中身に賭ける**ので、

- 曲を知っている人は、ほぼ確実に当てられる（やり込みの報酬）
- 曲を知らない人も、歌手キャラのクセや曲の雰囲気から山を張れる
- **賭け方**という第二の軸があるので、知識で劣る人が大穴一点張りで逆転できる

楽曲はすべてオリジナルなので、**誰もが初心者からスタート**します。
音楽に詳しい人だけが勝つゲームにはなりません。

## プレイ人数

| プラン | 人数 |
|---|---|
| 無料 | 2〜4人 |
| 有料 | 2〜10人 |

課金はホストのみ。参加者は常に無料で入れます。
