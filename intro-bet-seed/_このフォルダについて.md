# ⚠️ このフォルダは一時的な保管場所です

このフォルダの中身は **`intro-bet`（イントロベット）という別プロジェクト** の資料一式です。
クイズ集アプリとは何の関係もありません。

## なぜクイズ集のリポジトリに置いてあるのか

Claude Code のセッションに **GitHubの新規リポジトリ作成権限がなかった**ためです
（`POST /user/repos` が 403 で拒否されました。アクセス権が `Natsucoro/quiz` に限定されているため）。

作業内容が失われないよう、暫定的にこのブランチへ保管しています。

## ⚠️ このブランチを quiz の main にマージしないでください

別プロジェクトの資料が混入します。

## やってほしいこと

1. https://github.com/new で **`intro-bet`** を Private + README付きで作成する
2. https://claude.ai/admin-settings/claude-tag で `intro-bet` へのアクセスを Claude に許可する
3. Claude に「intro-bet 作ったよ」と伝える
   → このフォルダの中身をそのまま新リポジトリのルートへ移送し、このフォルダは削除します
